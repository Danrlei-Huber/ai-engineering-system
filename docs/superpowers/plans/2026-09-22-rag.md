# RAG Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the `engineering-rag` knowledge base under `rag/`: Docker Compose infra (Postgres + pgvector, Ollama, model pull), schema and migrations, a Markdown chunker, Ollama and fake embedding providers, an ingest CLI, a doctor CLI, a read-only MCP stdio server with four tools, tests, CI, the `/ingest-knowledge` skill, ADR-006, and the v0.1.0 release.

**Architecture:** One global database partitioned by `project` (scope) and `collection`. Agents only read through the MCP server; ingestion is an explicit CLI action. The server degrades instead of crashing when Postgres or Ollama are down. Library code lives in `rag/src/*.ts` as pure functions over an injected `Db` and `EmbeddingProvider`; thin `rag/src/cli/*.ts` and `rag/src/server.ts` wire them. Tests use a deterministic `fake` embedding provider so CI needs no Ollama.

**Tech Stack:** Node ≥ 22 (ESM, TypeScript 5.9), `@modelcontextprotocol/server` 2.0.0 (+ `@modelcontextprotocol/client` for tests), `zod` 4, `postgres` (Postgres.js) 3.4, `pgvector` 0.3, `yaml` 2.9, `vitest` 5, `tsx`, Docker Compose with `pgvector/pgvector:pg17` and `ollama/ollama`.

**Spec:** `docs/superpowers/specs/2026-09-22-ai-engineering-system-design.md` (section 5, plus 3, 6.3, 7). Depends on the plugin-core plan (`2026-09-22-plugin-core.md`) being complete: it needs `.mcp.json`, `hooks/scripts/session-banner.sh`, `skills/workflows/`, `docs/decisions/`, `.github/workflows/ci.yml`, `CHANGELOG.md`.

## Global Constraints

- Embedding contract, fixed for v0.1: model `bge-m3`, **1024** dimensions, **cosine** distance. Lives in `rag/src/contract.ts`; the number 1024 appears there and in `migrations/001_init.sql` only.
- Collections: `docs | decisions | standards | external`. Scope column is `project`; the plugin's own content uses project `_global`.
- All MCP tools are read-only. No tool writes to the database.
- The server must start and answer `rag_status` even when Postgres or Ollama are unreachable. A dimension mismatch is the only startup error that exits.
- Ingestion is Markdown only; unchanged files (same sha256) are skipped; deletion of vanished sources happens only with `--prune`.
- ESM everywhere: relative imports end in `.js`; `"type": "module"`.
- Credentials in compose and `.env.example` are development-only and labelled so.
- Integration tests run only when `RAG_RUN_INTEGRATION=1`; they need `RAG_TEST_DATABASE_URL` and use the fake provider.
- Commit after every task with a conventional-commit message ending in `Co-Authored-By: Claude Fable 5.1 <noreply@anthropic.com>`.

import { existsSync, readFileSync } from 'node:fs';
import { join } from 'node:path';
import YAML from 'yaml';
import { EMBED_MODEL_DEFAULT } from './contract.js';

export interface RagConfig {
  databaseUrl: string;
  ollamaUrl: string;
  embedModel: string;
  embedProvider: 'ollama' | 'fake';
  /** Project scope used when a tool call does not name one. */
  defaultProject: string | undefined;
}

export const DEFAULT_DATABASE_URL = 'postgres://rag:rag_local_only@localhost:5433/rag';
export const DEFAULT_OLLAMA_URL = 'http://localhost:11434';

/** Reads `project` from <cwd>/.ai-engineering/project.yaml; undefined when absent or unreadable. */
export function readProjectName(cwd: string): string | undefined {
  const file = join(cwd, '.ai-engineering', 'project.yaml');
  if (!existsSync(file)) return undefined;
  try {
    const doc: unknown = YAML.parse(readFileSync(file, 'utf8'));
    const project = (doc as { project?: unknown } | null)?.project;
    return typeof project === 'string' && project.trim() ? project.trim() : undefined;
  } catch {
    return undefined;
  }
}

export function loadConfig(env: NodeJS.ProcessEnv = process.env, cwd: string = process.cwd()): RagConfig {
  return {
    databaseUrl: env.RAG_DATABASE_URL ?? DEFAULT_DATABASE_URL,
    ollamaUrl: (env.OLLAMA_URL ?? DEFAULT_OLLAMA_URL).replace(/\/+$/, ''),
    embedModel: env.RAG_EMBED_MODEL ?? EMBED_MODEL_DEFAULT,
    embedProvider: env.RAG_EMBED_PROVIDER === 'fake' ? 'fake' : 'ollama',
    defaultProject: env.RAG_PROJECT ?? readProjectName(cwd),
  };
}
```

```ts
import { createHash } from 'node:crypto';

export interface Chunk {
  position: number;
  /** "Doc > Section > Subsection"; empty when the text precedes any heading. */
  headingPath: string;
  content: string;
}

export interface ChunkOptions {
  /** Sections longer than this are split by paragraph. Default 1800. */
  maxChars?: number;
}

const DEFAULT_MAX_CHARS = 1800;
const FENCE = /^\s*(```|~~~)/;
const HEADING = /^(#{1,6})\s+(.+?)\s*#*\s*$/;

interface Section {
  headingPath: string[];
  lines: string[];
}

export function extractTitle(markdown: string, fallback: string): string {
  const match = markdown.match(/^#\s+(.+?)\s*$/m);
  return match ? match[1].trim() : fallback;
}

export function chunkMarkdown(markdown: string, options: ChunkOptions = {}): Chunk[] {
  const maxChars = options.maxChars ?? DEFAULT_MAX_CHARS;
  const chunks: Chunk[] = [];
  for (const section of splitSections(markdown)) {
    const body = section.lines.join('\n').trim();
    if (!body) continue;
    const headingPath = section.headingPath.join(' > ');
    for (const content of splitOversized(body, maxChars)) {
      chunks.push({ position: chunks.length, headingPath, content });
    }
  }
  return chunks;
}

function splitSections(markdown: string): Section[] {
  const sections: Section[] = [{ headingPath: [], lines: [] }];
  const stack: { level: number; text: string }[] = [];
  let inFence = false;
  for (const line of markdown.split(/\r?\n/)) {
    if (FENCE.test(line)) inFence = !inFence;
    const heading = inFence ? null : line.match(HEADING);
    if (heading) {
      const level = heading[1].length;
      while (stack.length && stack[stack.length - 1].level >= level) stack.pop();
      stack.push({ level, text: heading[2].trim() });
      sections.push({ headingPath: stack.map((s) => s.text), lines: [] });
    } else {
      sections[sections.length - 1].lines.push(line);
    }
  }
  return sections;
}

/** Splits a section body into paragraphs and fenced code blocks (each fence is one block). */
function splitBlocks(body: string): string[] {
  const blocks: string[] = [];
  let buffer: string[] = [];
  let inFence = false;
  const flush = () => {
    const text = buffer.join('\n').trim();
    if (text) blocks.push(text);
    buffer = [];
  };
  for (const line of body.split('\n')) {
    if (FENCE.test(line)) {
      if (!inFence) flush();
      buffer.push(line);
      inFence = !inFence;
      if (!inFence) flush();
      continue;
    }
    if (!inFence && line.trim() === '') {
      flush();
      continue;
    }
    buffer.push(line);
  }
  flush();
  return blocks;
}

function splitOversized(body: string, maxChars: number): string[] {
  if (body.length <= maxChars) return [body];
  const out: string[] = [];
  let current: string[] = [];
  let size = 0;
  for (const block of splitBlocks(body)) {
    if (current.length && size + block.length + 2 > maxChars) {
      out.push(current.join('\n\n'));
      const last = current[current.length - 1];
      // one-paragraph overlap, unless that paragraph alone would dominate the next chunk
      current = last.length <= maxChars / 2 ? [last] : [];
      size = current.reduce((n, b) => n + b.length, 0);
    }
    current.push(block);
    size += block.length + 2;
  }
  if (current.length) out.push(current.join('\n\n'));
  return out;
}

/** Text that is embedded: heading path first so the vector carries document context. */
export function embedText(chunk: Chunk): string {
  return chunk.headingPath ? `${chunk.headingPath}\n\n${chunk.content}` : chunk.content;
}

/** Stable id for a chunk's meaning: sha256(headingPath + "\n" + content). Position is excluded on purpose. */
export function contentHash(chunk: Chunk): string {
  return createHash('sha256').update(chunk.headingPath).update('\n').update(chunk.content).digest('hex');
}
```

import { EMBED_DIMENSIONS } from './contract.js';

export interface EmbeddingProvider {
  readonly name: string;
  embed(texts: string[]): Promise<number[][]>;
}

export class DimensionMismatchError extends Error {
  constructor(provider: string, got: number, expected: number) {
    super(`Embedding contract violated: ${provider} returned ${got} dimensions, expected ${expected}. See docs/decisions/ADR-006.`);
    this.name = 'DimensionMismatchError';
  }
}

/** Ollama POST /api/embed (batch endpoint; /api/embeddings is superseded). */
export class OllamaEmbeddings implements EmbeddingProvider {
  readonly name: string;
  constructor(
    private readonly baseUrl: string,
    private readonly model: string,
    private readonly fetchImpl: typeof fetch = fetch,
    private readonly batchSize = 16,
  ) {
    this.name = `ollama:${model}`;
  }

  async embed(texts: string[]): Promise<number[][]> {
    const out: number[][] = [];
    for (let i = 0; i < texts.length; i += this.batchSize) {
      const input = texts.slice(i, i + this.batchSize);
      const res = await this.fetchImpl(`${this.baseUrl}/api/embed`, {
        method: 'POST',
        headers: { 'content-type': 'application/json' },
        body: JSON.stringify({ model: this.model, input }),
      });
      if (!res.ok) throw new Error(`Ollama /api/embed failed: ${res.status} ${await res.text()}`);
      const data = (await res.json()) as { embeddings?: unknown };
      if (!Array.isArray(data.embeddings) || data.embeddings.length !== input.length) {
        throw new Error('Ollama /api/embed returned an unexpected shape (expected embeddings[][] matching input length)');
      }
      out.push(...(data.embeddings as number[][]));
    }
    return out;
  }
}

/** Deterministic bag-of-words hashing, unit-normalised. For tests and CI only. */
export class FakeEmbeddings implements EmbeddingProvider {
  readonly name = 'fake';
  constructor(private readonly dims = EMBED_DIMENSIONS) {}
  async embed(texts: string[]): Promise<number[][]> {
    return texts.map((t) => fakeVector(t, this.dims));
  }
}

export function fakeVector(text: string, dims: number): number[] {
  const v = new Array<number>(dims).fill(0);
  for (const token of text.toLowerCase().split(/[^\p{L}\p{N}]+/u).filter(Boolean)) {
    let h = 2166136261;
    for (const ch of token) {
      h ^= ch.codePointAt(0)!;
      h = Math.imul(h, 16777619) >>> 0;
    }
    v[h % dims] += 1;
  }
  const norm = Math.sqrt(v.reduce((s, x) => s + x * x, 0)) || 1;
  return v.map((x) => x / norm);
}

export function createEmbeddingProvider(
  cfg: { embedProvider: 'ollama' | 'fake'; ollamaUrl: string; embedModel: string },
  fetchImpl?: typeof fetch,
): EmbeddingProvider {
  return cfg.embedProvider === 'fake' ? new FakeEmbeddings() : new OllamaEmbeddings(cfg.ollamaUrl, cfg.embedModel, fetchImpl);
}

/** Embeds a probe string and throws DimensionMismatchError if the provider breaks the contract. */
export async function assertDimension(provider: EmbeddingProvider, expected = EMBED_DIMENSIONS): Promise<void> {
  const [vector] = await provider.embed(['embedding dimension probe']);
  const got = vector?.length ?? 0;
  if (got !== expected) throw new DimensionMismatchError(provider.name, got, expected);
}

import { readdirSync, readFileSync } from 'node:fs';
import { dirname, join } from 'node:path';
import { fileURLToPath } from 'node:url';
import type { Db } from './db.js';

// Works from src/ (tsx) and from dist/ (node): both are one level under rag/.
export const MIGRATIONS_DIR = join(dirname(fileURLToPath(import.meta.url)), '..', 'migrations');

export function listMigrationFiles(dir: string = MIGRATIONS_DIR): string[] {
  return readdirSync(dir).filter((f) => f.endsWith('.sql')).sort();
}

export async function appliedMigrations(sql: Db): Promise<string[]> {
  await sql`create table if not exists schema_migrations (name text primary key, applied_at timestamptz not null default now())`;
  const rows = await sql<{ name: string }[]>`select name from schema_migrations order by name`;
  return rows.map((r) => r.name);
}

export async function pendingMigrations(sql: Db, dir: string = MIGRATIONS_DIR): Promise<string[]> {
  const applied = new Set(await appliedMigrations(sql));
  return listMigrationFiles(dir).filter((f) => !applied.has(f));
}

/** Applies each pending migration in its own transaction. Returns the names applied. */
export async function migrate(sql: Db, dir: string = MIGRATIONS_DIR): Promise<string[]> {
  const pending = await pendingMigrations(sql, dir);
  for (const name of pending) {
    const body = readFileSync(join(dir, name), 'utf8');
    await sql.begin(async (tx) => {
      await tx.unsafe(body);
      await tx`insert into schema_migrations (name) values (${name})`;
    });
  }
  return pending;
}

import pgvector from 'pgvector';
import type { Collection } from './contract.js';

export interface SourceInput {
  project: string;
  collection: Collection;
  path?: string;
  url?: string;
  title: string;
  sha256: string;
  metadata?: Record<string, unknown>;
}

export interface SourceRow {
  id: string;
  project: string;
  collection: Collection;
  path: string | null;
  url: string | null;
  title: string | null;
  sha256: string;
  metadata: Record<string, unknown>;
  ingested_at: Date;
}

export interface SourceSummary extends SourceRow {
  chunk_count: number;
}

export interface ChunkInput {
  position: number;
  headingPath: string;
  content: string;
  contentHash: string;
  embedding: number[];
}

export interface StoredChunk {
  position: number;
  heading_path: string;
  content: string;
  content_hash: string;
}

export interface SearchHit extends StoredChunk {
  chunk_id: number;
  source_id: string;
  project: string;
  collection: Collection;
  path: string | null;
  url: string | null;
  title: string | null;
  score: number;
}

export async function findSource(sql: Db, project: string, collection: Collection, origin: string): Promise<SourceRow | undefined> {
  const rows = await sql<SourceRow[]>`
    select * from sources
    where project = ${project} and collection = ${collection} and coalesce(path, url) = ${origin}`;
  return rows[0];
}

/** Inserts or updates the source row, then replaces all of its chunks. One transaction. */
export async function upsertSourceWithChunks(sql: Db, source: SourceInput, chunks: ChunkInput[]): Promise<string> {
  const id = await sql.begin(async (tx) => {
    const [row] = await tx<{ id: string }[]>`
      insert into sources (project, collection, path, url, title, sha256, metadata, ingested_at)
      values (${source.project}, ${source.collection}, ${source.path ?? null}, ${source.url ?? null},
              ${source.title}, ${source.sha256}, ${tx.json(source.metadata ?? {})}, now())
      on conflict (project, collection, (coalesce(path, url)))
      do update set title = excluded.title, sha256 = excluded.sha256, metadata = excluded.metadata, ingested_at = now()
      returning id`;
    await tx`delete from chunks where source_id = ${row.id}`;
    for (const c of chunks) {
      await tx`
        insert into chunks (source_id, position, heading_path, content, content_hash, embedding)
        values (${row.id}, ${c.position}, ${c.headingPath}, ${c.content}, ${c.contentHash}, ${pgvector.toSql(c.embedding)}::vector)`;
    }
    return row.id;
  });
  return id as string;
}

export interface SearchOptions {
  /** Omit to search every project. */
  projects?: string[];
  collections: Collection[];
  limit: number;
}

export async function searchChunks(sql: Db, embedding: number[], opts: SearchOptions): Promise<SearchHit[]> {
  const vec = pgvector.toSql(embedding);
  const allProjects = opts.projects === undefined;
  const projects = opts.projects ?? [];
  return sql<SearchHit[]>`
    select c.id as chunk_id, c.source_id, c.position, c.heading_path, c.content, c.content_hash,
           s.project, s.collection, s.path, s.url, s.title,
           1 - (c.embedding <=> ${vec}::vector) as score
    from chunks c
    join sources s on s.id = c.source_id
    where (${allProjects} or s.project = any(${projects}))
      and s.collection = any(${opts.collections})
    order by c.embedding <=> ${vec}::vector
    limit ${opts.limit}`;
}

export async function listSources(sql: Db, filter: { project?: string; collection?: Collection } = {}): Promise<SourceSummary[]> {
  return sql<SourceSummary[]>`
    select s.*, count(c.id)::int as chunk_count
    from sources s
    left join chunks c on c.source_id = s.id
    where (${filter.project === undefined} or s.project = ${filter.project ?? ''})
      and (${filter.collection === undefined} or s.collection = ${filter.collection ?? ''})
    group by s.id
    order by s.project, s.collection, coalesce(s.path, s.url)`;
}

export async function getSourceWithChunks(sql: Db, id: string): Promise<{ source: SourceRow; chunks: StoredChunk[] } | undefined> {
  const [source] = await sql<SourceRow[]>`select * from sources where id = ${id}`;
  if (!source) return undefined;
  const chunks = await sql<StoredChunk[]>`
    select position, heading_path, content, content_hash from chunks where source_id = ${id} order by position`;
  return { source, chunks };
}

/** Deletes path-based sources under `pathPrefix` whose path is not in `keepOrigins`. Returns deleted paths. */
export async function pruneSources(sql: Db, project: string, collection: Collection, pathPrefix: string, keepOrigins: string[]): Promise<string[]> {
  const rows = await sql<{ path: string }[]>`
    delete from sources
    where project = ${project} and collection = ${collection}
      and path is not null and path like ${pathPrefix + '%'}
      and path <> all(${keepOrigins})
    returning path`;
  return rows.map((r) => r.path).sort();
}

export async function countChunks(sql: Db): Promise<number> {
  const [row] = await sql<{ n: number }[]>`select count(*)::int as n from chunks`;
  return row.n;
}

import { createHash } from 'node:crypto';
import { existsSync, readdirSync, readFileSync, statSync } from 'node:fs';
import { basename, isAbsolute, join, relative, resolve, sep } from 'node:path';
import { parseArgs } from 'node:util';
import { chunkMarkdown, contentHash, embedText, extractTitle } from './chunker.js';
import { COLLECTIONS, isCollection, type Collection } from './contract.js';
import { findSource, pruneSources, upsertSourceWithChunks, type Db } from './db.js';
import type { EmbeddingProvider } from './embeddings.js';

export interface IngestOptions {
  project: string;
  collection: Collection;
  /** Files or directories, relative to `root` (or absolute). */
  targets: string[];
  /** Base directory that stored paths are relative to. */
  root: string;
  /** External origin; requires exactly one file target. */
  url?: string;
  title?: string;
  prune?: boolean;
  metadata?: Record<string, unknown>;
}

export interface IngestReport {
  ingested: string[];
  skipped: string[];
  pruned: string[];
}

const SKIP_DIRS = new Set(['node_modules', '.git', 'dist', '.planning']);

export function listMarkdownFiles(target: string): string[] {
  if (!existsSync(target)) return [];
  const stat = statSync(target);
  if (stat.isFile()) return [target];
  const out: string[] = [];
  const walk = (dir: string) => {
    for (const entry of readdirSync(dir, { withFileTypes: true })) {
      if (entry.isDirectory()) {
        if (!SKIP_DIRS.has(entry.name)) walk(join(dir, entry.name));
      } else if (/\.md$/i.test(entry.name)) {
        out.push(join(dir, entry.name));
      }
    }
  };
  walk(target);
  return out.sort();
}

function toPosix(p: string): string {
  return p.split(sep).join('/');
}

export async function ingest(sql: Db, provider: EmbeddingProvider, opts: IngestOptions, log: (line: string) => void = () => {}): Promise<IngestReport> {
  const report: IngestReport = { ingested: [], skipped: [], pruned: [] };
  const seen: string[] = [];

  for (const target of opts.targets) {
    const absTarget = isAbsolute(target) ? target : resolve(opts.root, target);
    for (const abs of listMarkdownFiles(absTarget)) {
      const rel = toPosix(relative(opts.root, abs));
      const text = readFileSync(abs, 'utf8');
      const sha256 = createHash('sha256').update(text).digest('hex');
      const origin = opts.url ?? rel;
      seen.push(origin);

      const existing = await findSource(sql, opts.project, opts.collection, origin);
      if (existing?.sha256 === sha256) {
        report.skipped.push(rel);
        log(`skip     ${rel}`);
        continue;
      }

      const chunks = chunkMarkdown(text);
      const vectors = chunks.length ? await provider.embed(chunks.map(embedText)) : [];
      const metadata: Record<string, unknown> = { ...(opts.metadata ?? {}) };
      if (opts.url) metadata.retrieved_at = new Date().toISOString();

      await upsertSourceWithChunks(
        sql,
        {
          project: opts.project,
          collection: opts.collection,
          path: opts.url ? undefined : rel,
          url: opts.url,
          title: opts.title ?? extractTitle(text, basename(rel)),
          sha256,
          metadata,
        },
        chunks.map((c, i) => ({ position: c.position, headingPath: c.headingPath, content: c.content, contentHash: contentHash(c), embedding: vectors[i] })),
      );
      report.ingested.push(rel);
      log(`ingested ${rel} (${chunks.length} chunks)`);
    }
  }

  if (opts.prune && !opts.url) {
    for (const target of opts.targets) {
      const absTarget = isAbsolute(target) ? target : resolve(opts.root, target);
      if (!existsSync(absTarget) || !statSync(absTarget).isDirectory()) continue;
      const prefix = toPosix(relative(opts.root, absTarget)) + '/';
      const deleted = await pruneSources(sql, opts.project, opts.collection, prefix, seen);
      report.pruned.push(...deleted);
      for (const p of deleted) log(`pruned   ${p}`);
    }
  }
  return report;
}

export function parseIngestArgs(argv: string[], ctx: { defaultProject: string | undefined; cwd: string }): IngestOptions {
  const { values, positionals } = parseArgs({
    args: argv,
    allowPositionals: true,
    options: {
      project: { type: 'string' },
      collection: { type: 'string' },
      root: { type: 'string' },
      url: { type: 'string' },
      title: { type: 'string' },
      prune: { type: 'boolean', default: false },
    },
  });
  const project = values.project ?? ctx.defaultProject;
  if (!project) throw new Error('--project is required (or run inside a project with .ai-engineering/project.yaml)');
  const collection = values.collection ?? '';
  if (!isCollection(collection)) throw new Error(`--collection must be one of ${COLLECTIONS.join(', ')}`);
  if (positionals.length === 0) throw new Error('at least one target (file or directory) is required');
  if (values.url && positionals.length !== 1) throw new Error('--url requires exactly one file target');
  return {
    project,
    collection,
    targets: positionals,
    root: values.root ? resolve(ctx.cwd, values.root) : ctx.cwd,
    url: values.url,
    title: values.title,
    prune: values.prune ?? false,
    metadata: undefined,
  };
}

```ts
import { existsSync } from 'node:fs';
import { dirname, join } from 'node:path';
import { fileURLToPath } from 'node:url';
import type { RagConfig } from './config.js';
import { EMBED_DIMENSIONS } from './contract.js';
import { countChunks, type Db } from './db.js';
import { assertDimension, type EmbeddingProvider } from './embeddings.js';
import { pendingMigrations } from './migrate.js';

export interface Check { name: string; ok: boolean; detail: string }
export interface RagStatus { ok: boolean; checks: Check[] }

export const DEFAULT_DIST_PATH = join(dirname(fileURLToPath(import.meta.url)), '..', 'dist', 'server.js');

async function run(name: string, fn: () => Promise<string>): Promise<Check> {
  try {
    return { name, ok: true, detail: await fn() };
  } catch (err) {
    return { name, ok: false, detail: (err as Error).message };
  }
}

export async function collectStatus(
  cfg: RagConfig,
  deps: { sql?: Db; provider?: EmbeddingProvider; fetchImpl?: typeof fetch; distPath?: string } = {},
): Promise<RagStatus> {
  const fetchImpl = deps.fetchImpl ?? fetch;
  const checks: Check[] = [];

  checks.push(await run('node', async () => {
    const major = Number(process.versions.node.split('.')[0]);
    if (major < 22) throw new Error(`v${process.versions.node} (need >= 22)`);
    return `v${process.versions.node}`;
  }));

  let dbOk = false;
  if (deps.sql) {
    const sql = deps.sql;
    checks.push(await run('postgres', async () => { await sql`select 1`; dbOk = true; return cfg.databaseUrl.replace(/\/\/.*@/, '//***@'); }));
    if (dbOk) {
      checks.push(await run('pgvector', async () => {
        const [row] = await sql<{ extversion: string }[]>`select extversion from pg_extension where extname = 'vector'`;
        if (!row) throw new Error('extension "vector" not installed; run npm run migrate');
        return `v${row.extversion}`;
      }));
      checks.push(await run('migrations', async () => {
        const pending = await pendingMigrations(sql);
        if (pending.length) throw new Error(`pending: ${pending.join(', ')} (run npm run migrate)`);
        return 'up to date';
      }));
      checks.push(await run('chunks', async () => `${await countChunks(sql)} indexed`));
    }
  }

  checks.push({ name: 'embedding provider', ok: true, detail: cfg.embedProvider === 'fake' ? 'fake (tests/CI only)' : `ollama ${cfg.embedModel} at ${cfg.ollamaUrl}` });

  if (cfg.embedProvider === 'ollama') {
    checks.push(await run('ollama', async () => {
      const res = await fetchImpl(`${cfg.ollamaUrl}/api/tags`);
      if (!res.ok) throw new Error(`GET /api/tags -> ${res.status}`);
      const data = (await res.json()) as { models?: { name: string }[] };
      const names = (data.models ?? []).map((m) => m.name);
      const present = names.some((n) => n === cfg.embedModel || n.startsWith(`${cfg.embedModel}:`));
      if (!present) throw new Error(`model ${cfg.embedModel} not pulled (have: ${names.join(', ') || 'none'}); run docker compose up ollama-pull`);
      return `reachable, ${cfg.embedModel} present`;
    }));
  }

  if (deps.provider) {
    const provider = deps.provider;
    checks.push(await run('embedding dimension', async () => { await assertDimension(provider); return `${EMBED_DIMENSIONS}`; }));
  }

  const distPath = deps.distPath ?? DEFAULT_DIST_PATH;
  checks.push(await run('mcp build', async () => {
    if (!existsSync(distPath)) throw new Error(`${distPath} missing; run npm run build`);
    return distPath;
  }));

  return { ok: checks.every((c) => c.ok), checks };
}

import type { RagConfig } from './config.js';
import { COLLECTIONS, GLOBAL_PROJECT, type Collection } from './contract.js';
import { getSourceWithChunks, listSources, searchChunks, type Db, type SearchHit, type SourceSummary } from './db.js';
import type { EmbeddingProvider } from './embeddings.js';
import { collectStatus, type RagStatus } from './status.js';

export interface ToolDeps {
  sql: Db;
  provider: EmbeddingProvider;
  cfg: RagConfig;
}

export interface SearchArgs {
  query: string;
  project?: string;
  collections?: Collection[];
  limit?: number;
}

/** Default scope: the named (or configured) project plus _global. No project known: every project. */
export async function searchKnowledge(deps: ToolDeps, args: SearchArgs): Promise<SearchHit[]> {
  const project = args.project ?? deps.cfg.defaultProject;
  const projects = project ? [project, GLOBAL_PROJECT] : undefined;
  const [embedding] = await deps.provider.embed([args.query]);
  return searchChunks(deps.sql, embedding, {
    projects,
    collections: args.collections?.length ? args.collections : [...COLLECTIONS],
    limit: args.limit ?? 8,
  });
}

export async function listSourcesTool(deps: ToolDeps, args: { project?: string; collection?: Collection }): Promise<SourceSummary[]> {
  return listSources(deps.sql, args);
}

export class SourceNotFoundError extends Error {
  constructor(id: string) {
    super(`source ${id} not found`);
    this.name = 'SourceNotFoundError';
  }
}

export async function getSourceTool(deps: ToolDeps, args: { source_id: string }) {
  const found = await getSourceWithChunks(deps.sql, args.source_id);
  if (!found) throw new SourceNotFoundError(args.source_id);
  const document = found.chunks.map((c) => (c.heading_path ? `## ${c.heading_path}\n\n${c.content}` : c.content)).join('\n\n');
  return { ...found, document };
}

export async function ragStatusTool(deps: ToolDeps): Promise<RagStatus> {
  return collectStatus(deps.cfg, { sql: deps.sql, provider: deps.provider });
}

const BRING_UP = 'Start it with: cd <plugin>/rag && docker compose up -d && npm run migrate';

export function describeError(err: unknown): string {
  const msg = err instanceof Error ? err.message : String(err);
  if (err instanceof SourceNotFoundError) return msg;
  if (/ECONNREFUSED|ENOTFOUND|ETIMEDOUT|CONNECT_TIMEOUT|connection|Connection terminated|password authentication/i.test(msg) && !/11434|ollama/i.test(msg)) {
    return `RAG database unreachable (${msg}). ${BRING_UP}`;
  }
  if (/11434|ollama|fetch failed/i.test(msg)) {
    return `Ollama unreachable or model missing (${msg}). Start it with: cd <plugin>/rag && docker compose up -d ollama ollama-pull`;
  }
  return `RAG error: ${msg}. Run 'npm run doctor' in the rag/ directory for a full check.`;
}

```ts
import { McpServer } from '@modelcontextprotocol/server';
import { StdioServerTransport } from '@modelcontextprotocol/server/stdio';
import { pathToFileURL } from 'node:url';
import * as z from 'zod';
import { loadConfig } from './config.js';
import { COLLECTIONS } from './contract.js';
import { createDb } from './db.js';
import { DimensionMismatchError, assertDimension, createEmbeddingProvider } from './embeddings.js';
import { describeError, getSourceTool, listSourcesTool, ragStatusTool, searchKnowledge, type ToolDeps } from './tools.js';

const SERVER_VERSION = '0.1.0';

function ok(data: unknown) {
  return { content: [{ type: 'text' as const, text: JSON.stringify(data, null, 2) }] };
}
function fail(err: unknown) {
  return { isError: true, content: [{ type: 'text' as const, text: describeError(err) }] };
}

export function buildServer(deps: ToolDeps): McpServer {
  const server = new McpServer({ name: 'engineering-rag', version: SERVER_VERSION });

  server.registerTool(
    'search_knowledge',
    {
      description: 'Semantic search over the engineering knowledge base (cosine, top-k). Default scope: the current project plus _global. Returns chunks with heading_path, source location, collection, project, source_id, content_hash and score. Read-only.',
      inputSchema: z.object({
        query: z.string().min(1),
        project: z.string().min(1).optional(),
        collections: z.array(z.enum(COLLECTIONS)).optional(),
        limit: z.number().int().min(1).max(50).optional(),
      }),
    },
    async (args) => { try { return ok(await searchKnowledge(deps, args)); } catch (e) { return fail(e); } },
  );

  server.registerTool(
    'list_sources',
    {
      description: 'List indexed sources (documents) with chunk counts, optionally filtered by project and collection. Read-only.',
      inputSchema: z.object({ project: z.string().min(1).optional(), collection: z.enum(COLLECTIONS).optional() }),
    },
    async (args) => { try { return ok(await listSourcesTool(deps, args)); } catch (e) { return fail(e); } },
  );

  server.registerTool(
    'get_source',
    {
      description: 'Return one source with all its chunks in order and the rebuilt document text. Use after search_knowledge when a chunk needs its full context before citing it. Read-only.',
      inputSchema: z.object({ source_id: z.string().uuid() }),
    },
    async (args) => { try { return ok(await getSourceTool(deps, args)); } catch (e) { return fail(e); } },
  );

  server.registerTool(
    'rag_status',
    {
      description: 'Health of the knowledge base: Postgres, pgvector, migrations, chunk count, Ollama, model, embedding dimension, build. Call this first when other tools fail.',
      inputSchema: z.object({}),
    },
    async () => { try { return ok(await ragStatusTool(deps)); } catch (e) { return fail(e); } },
  );

  return server;
}

async function main(): Promise<void> {
  const cfg = loadConfig();
  const sql = createDb(cfg.databaseUrl);
  const provider = createEmbeddingProvider(cfg);

  // Fail fast only on a contract violation. Connectivity problems degrade to tool-level errors.
  try {
    await assertDimension(provider);
  } catch (err) {
    if (err instanceof DimensionMismatchError) {
      console.error(err.message);
      process.exit(1);
    }
    console.error(`[engineering-rag] embedding provider unavailable at startup: ${(err as Error).message}`);
  }

  const server = buildServer({ sql, provider, cfg });
  await server.connect(new StdioServerTransport());
  console.error(`[engineering-rag] v${SERVER_VERSION} ready (project: ${cfg.defaultProject ?? 'none'}, provider: ${provider.name})`);
}

if (process.argv[1] && import.meta.url === pathToFileURL(process.argv[1]).href) {
  main().catch((err) => {
    console.error(`[engineering-rag] fatal: ${(err as Error).message}`);
    process.exit(1);
  });
}
```

- [ ] **Step 3: Write ADR-006**

```markdown
# ADR-006: The RAG is global, read-only for agents, with a fixed embedding contract

Status: Accepted (2026-09-22)

## Context
Agents need architecture decisions, standards and project docs at hand without re-reading whole repositories. Letting agents write to shared memory creates a feedback loop where one agent's belief becomes another's "established decision". Embedding models with different dimensions cannot share an index.

## Decision
One PostgreSQL + pgvector database, run from `rag/docker-compose.yml`, partitioned by `project` (scope, `_global` for plugin content) and `collection` (`docs | decisions | standards | external`). The MCP server `engineering-rag` exposes only read tools (`search_knowledge`, `list_sources`, `get_source`, `rag_status`). Ingestion happens only through the CLI (`/ingest-knowledge` wraps it) and is incremental by sha256, pruning only with `--prune`. Only `research` and `architect` hold the RAG tools. Embedding contract for v0.1: Ollama `bge-m3`, 1024 dimensions, cosine distance; the server refuses to start on a dimension mismatch, but keeps running when Postgres or Ollama are merely unreachable.

## Consequences
Knowledge has a human-controlled origin. Changing the embedding model means a new migration and a full re-ingest, and is itself an ADR. Hybrid search, reranking and source-code ingestion are deferred until evals show a need. The RAG is a degradable dependency: research degrades to codebase-only and says so (`rag_available: false`).
```
