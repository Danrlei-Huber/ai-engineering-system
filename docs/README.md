# docs/

- `decisions/` — the ADRs (short form), ingested into the RAG `standards` collection under `_global`.
  Any architectural change gets one before the code.
- `PENDING.md` — what is still open, grouped by who can act on it. Resolved items live in
  `CHANGELOG.md`, not here.
- `superpowers/specs/` — the 2026-09-22 design, kept as written; the as-built state is in the README,
  the ADRs and the CHANGELOG.
- `superpowers/plans/` — the two implementation plans that produced v0.1.0, executed and merged;
  their checkboxes were tracked outside git.
